# Google Calendar Mastery Skill

Follow these actionable instructions to configure, manage, and optimize Google Calendar workflows, events, appointment schedules, and integrations.

---

## 1. Calendar Setup & Customization

### Accessing Google Calendar
- Access via `calendar.google.com` or the Google Apps waffle menu on Google sites.
- Google Calendar displays a **collection of multiple calendars** overlaid in a single view.

### Creating & Organizing Calendars
1. In the left panel, locate **Other calendars** and click the **`+`** icon.
2. Select **Create new calendar**.
3. Set the **Name**, **Description**, and **Time zone**, then click **Create calendar**.
4. **Color Coding**: Click the 3 dots next to any calendar in the left panel to assign custom color codes for quick visual differentiation.
5. **World Clock Setup**:
   - Go to **Settings (Gear icon)** > **Settings** > **World clock**.
   - Check **Show world clock** and add desired secondary time zones (e.g., Santiago, Paris, Sydney).

## 2. Event Creation Workflows

Always verify which specific calendar an event belongs to before saving.

### Method 1: Quick Single-Click Creation
- Click on any target date on the grid.
- Type the title and optional time directly in the title box (e.g., `Unit 10 Test 10:00 AM`). Google Calendar auto-parses the time.
- Toggle **All day** or adjust start/end times if necessary.

### Method 2: Double-Click Full Interface
- Double-click a target date to open the complete event creation panel.
- Use for multi-day events, custom repeating rules (annually, weekly, weekdays, custom intervals), adding video conferencing (Google Meet), locations, descriptions, and custom notifications.

### Method 3: "Create" Button
- Click **`+ Create`** > **Event** in the top-left sidebar. Specify date, time, and target calendar manually.

### Method 4: Browser URL Shortcut
- Type `cal.new` directly into the browser address bar to launch a fresh event creation screen instantly.

## 3. Advanced Event Management

### Find a Time Tool
1. In the full event panel, click **Find a time**.
2. Add guests in the **Guests** field.
3. Click **Suggested times** to automatically identify overlapping availability across guest schedules.

### Event Attachments & Permissions
1. In the event details, click the **Paperclip icon** (Description area).
2. Select files from Google Drive (e.g., docs, PDFs, practice quizzes) or upload new files.
3. **Crucial Access Rule**: Ensure attached Drive files are set to *"Anyone with the link can view"* if sharing with external attendees or public calendar viewers.

### Custom Notifications
- Notifications set on events are **personal to the calendar owner** (they do not spam guest/public calendars).
- **Email Notifications**: Set lead times (e.g., 2 days before) for advance preparation.
- **In-Browser Popups**: Set short lead times (e.g., 10–45 minutes before) for real-time reminders.

## 4. Calendar Sharing & Permissions

1. Hover over a target calendar in the left panel, click the 3 dots, and select **Settings and sharing**.
2. **Specific People / Groups**:
   - Under *Share with specific people*, enter email addresses or Google Contacts groups (e.g., Faculty list).
   - Set permission levels: *See only free/busy*, *See all event details*, *Make changes to events*, or *Make changes and manage sharing*.
3. **Public Calendar Sharing**:
   - Check **Make available to public** (ensure no private student/personal info is included).
   - Click **Get shareable link** to embed or distribute the calendar link via email or website.
4. **Exporting**: Use **Export calendar** to generate an ICS file for Microsoft Outlook or other external tools.

## 5. Professional Appointment Schedules

Use Appointment Schedules to allow clients, parents, or students to book time slots directly.

1. Click **`+ Create`** > **Appointment schedule**.
2. **Configuration Settings**:
   - Set title and appointment duration (e.g., 30 minutes).
   - Select repeating or non-repeating dates and specific daily time windows (e.g., 2:30 PM – 8:30 PM).
3. **Scheduling Restrictions**:
   - **Scheduling Window**: Set how far in advance appointments can be booked (e.g., 10 days out) and minimum advance notice.
   - **Buffer Time**: Add rest/prep intervals between slots (e.g., 5 minutes).
   - **Maximum Daily Bookings**: Cap the maximum number of appointments per day.
4. **Booking Form**: Customize required fields (First/Last name, Email, phone, custom questions) and confirmation reminders.

## 6. Keyboard Shortcuts & Side Panel Integration

### Essential Keyboard Shortcuts
Press **`Shift + ?`** anywhere in Google Calendar to open the full shortcut cheat sheet.

| Action | Shortcut Key |
| :--- | :--- |
| **Day View** | `D` or `1` |
| **Week View** | `W` or `2` |
| **Month View** | `M` |
| **Custom View** | `X` |
| **Schedule View** | `A` |
| **Year View** | `Y` |
| **Next Period** | `J` or `N` |
| **Previous Period** | `K` or `P` |
| **Jump to Date** | `G` |
| **Create Event** | `C` |

### Side Panel Integrations
- **Google Keep**: Capture quick notes without navigating away from the schedule.
- **Google Tasks**: View task lists and **drag-and-drop tasks directly onto calendar days** to schedule them.
- **Google Contacts & Maps**: Quick lookup for guest addresses and meeting locations.
